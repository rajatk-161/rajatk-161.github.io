# Rajat Kumar: personal website

All files sit in one folder, so they can be uploaded to GitHub in one step.

- index.html: the page (all text)
- style.css: colours, fonts, layout
- main.js: live lattice animation; shows the CV button once Rajat_Kumar_CV.pdf exists
- portrait.jpg: profile photo
- og-image.png: preview image for shared links
- llt-phase-diagram.svg, decompression-signature.svg, glycerol-soft-confinement.svg, shear-amorphous-ice.svg: research figures
- .nojekyll: tells GitHub Pages to serve files as they are (optional)

To add a CV, upload a file named exactly Rajat_Kumar_CV.pdf next to index.html.
To edit text, open index.html on GitHub, click the pencil icon, edit, and commit.
